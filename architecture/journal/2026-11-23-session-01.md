## 1. User Mandate & Core Aesthetic Articulated

- Scope expanded from cleaning up `meta/` to a **full ground-up architectural audit and redesign of all of `nixconf`** (including `primitives/` and everything else, with zero sunk-cost attachment).
- **Mathematical elegance philosophy**: Find minimal, orthogonal, maximally expressive fundamental primitives from which concrete systems emerge naturally — avoiding shallow alias layers, premature abstractions, and unnecessary custom DSLs.
- **Standards with discipline**: Adopt mature, well-maintained standards/tools where they genuinely add value; avoid brittle/bloated dependencies; build clean owned implementations (including pure Rust integration) where appropriate.
- **Long-term capability & fleet horizon** explicitly captured in [`CHARTER.md`](../CHARTER.md):
  - Planned heterogeneous fleet: `astrolabe` (VPS), `x240`, Live USB/installer ISO, WSL, Asus ZenBook Duo, older TUF gaming laptop, Lenovo Chromebook tablet, Raspberry Pi (`aarch64-linux`), and future hosts — plus trivial provisioning commands/ISO.
  - Tailscale (or alternative mesh fabric) considered at a fundamental architectural level.
  - GitOps & automated updates (e.g., `system.autoUpgrade` vs alternatives, GitHub source of truth, PR-based workflow for agents/bots, auto-deploy from `main`, keeping security-critical services like Vaultwarden current, repo backup / self-hosted mirror).
  - Distributed storage & compute across the fleet.
  - Deep observability within storage/RAM constraints (evaluating alternatives to VictoriaMetrics/VictoriaLogs/Alloy/Grafana + periodic autonomous analysis agent).
  - Documentation & LLM knowledge architecture (in-repo vs external, uniform enforcement across all layers, compact LLM ingestion).
